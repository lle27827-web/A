---
name: Desktop full-bleed layout
description: Desktop workspaces should use the available screen width without changing the phone layout.
---

Signed-in desktop workspaces should fill the available viewport edge-to-edge; preserve the existing phone layout and prevent horizontal overflow.

**Why:** the user asked for the logged-in computer interface to reach the screen edges and use the full screen.

**How to apply:** scope full-width and full-height layout rules to desktop breakpoints for both facility and personal workspaces. Keep enough internal spacing for controls and content, preserve independently scrollable panels, and do not try to control browser fullscreen chrome.
