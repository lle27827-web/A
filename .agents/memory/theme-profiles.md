---
name: Theme profiles
description: Product requirements for keeping the built-in SỔ CÔNG themes independent from user-created color customization.
---

Use one yellow default theme. Do not expose dark-mode, custom-theme, or theme-selection controls in Settings. Previously selected dark/custom themes should resolve to the yellow default.

**Why:** The user asked to remove the dark interface and theme options.

**How to apply:** Keep the current yellow appearance and avoid adding dark/custom theme choices unless the user asks to restore them.
