---
name: Theme profiles
description: Product requirements for keeping the built-in SỔ CÔNG themes independent from user-created color customization.
---

Keep the built-in yellow and dark-gray themes as separate defaults. Users may edit either preset only through its explicit edit action; opening the general color editor creates/edits a third, independent custom theme. Brown-filled surfaces use the revenue-style grays (outer panels #5a5a5a, inner rows #454545) with the same frame treatment as revenue; only the global search field and Settings gear keep brown fills.

Application text and numbers stay semibold or heavier, with headings and key figures receiving stronger emphasis for clear visual hierarchy. Use Be Vietnam Pro for Vietnamese interface copy and Manrope for display headings. The Settings gear remains brown; settings rows and edit controls use revenue gray with light text. Employee/card creation actions, service-selection controls, employee attendance/detail choices, and employee/card list surfaces use revenue gray with light text. Sign-out buttons are warm off-white with brown text. The personal timesheet canvas and header are yellow in both built-in themes; its card and row surfaces use revenue gray with bold white text. Home management shortcuts are white, return controls are dark green, and the global search field is dark brown with light text. Editable fields remain white. Employee names and all text inside employee-detail and revenue panels must be pure white. Destructive actions retain red text and borders.

**Why:** The user wants custom color choices not to overwrite or unexpectedly alter the two built-in interfaces, prefers bold text, and explicitly changed all brown-filled surfaces to revenue gray while retaining brown only for global search and the Settings gear. They reported employee names stayed dark after a prior white-text change, so explicit scoped overrides are needed after page-level foreground rules. A hierarchy keeps bold text readable and makes headings and figures easier to scan.

**How to apply:** When changing theme selection, palette storage, or theme controls, preserve independent palettes for the yellow, dark-gray, and custom profiles; keep reset actions scoped to the active profile. When old saved palettes contain brown surface colors, migrate those surfaces to gray without changing the search field or Settings gear. Keep app text semibold or heavier, emphasize headings and key figures, and use Be Vietnam Pro/Manrope as the interface/display font pair. Preserve the yellow personal canvas, white editable fields and home shortcuts, green return controls, white text in employee/revenue panels, and red destructive actions.
