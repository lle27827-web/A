name: Keyboard shortcut storage
description: The user's scope preference for keyboard shortcut persistence.
---

Store SỔ CÔNG keyboard shortcut bindings locally on each device/browser. Do not sync bindings to the user's account or other devices.

**Why:** the user chose device-only storage for keyboard shortcuts.

**How to apply:** keep shortcut capture, management, and storage device-local unless the user changes this requirement.
